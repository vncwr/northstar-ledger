# Northstar Ledger

Northstar Ledger is a responsive financial operations dashboard for a growing studio. It includes KPI cards, a Recharts revenue view, runway health module, searchable transactions, responsive navigation, and light/dark mode.

## Setup
`npm install && npm run dev`

## Vercel deployment

Import this repository into Vercel with the project root as the deployment root. The included `vercel.json` configures the Next.js framework, `npm ci` installation, and `npm run build` production command. Node.js 20 or newer is declared in `package.json`.
