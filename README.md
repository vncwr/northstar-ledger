# Northstar Ledger

Northstar Ledger is a responsive financial operations dashboard for a growing studio. It includes KPI cards, a Recharts revenue view, runway health module, searchable transactions, responsive navigation, and light/dark mode.

## Setup
`npm install && npm run dev`

## Upwork portfolio blurb
I built Northstar Ledger as a focused financial workspace for an agency team that needs clarity without spreadsheet fatigue. The interface balances dense data, responsive behavior, theme switching, charts, and accessible table interactions.
